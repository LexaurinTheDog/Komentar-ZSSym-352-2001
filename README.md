# Komentář k zákonu č. 352/2001 Sb., o užívání státních symbolů České republiky a o změně některých zákonů

Otevřený komentář k zákonu o užívání státních symbolů — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; oprávněné osoby, velký a malý státní znak, úřední razítka, státní vlajka a pravidla jejího vyvěšování, vlajka prezidenta republiky, státní pečeť, státní hymna a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2001-00352_2022-01-01`.
